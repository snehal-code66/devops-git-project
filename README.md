# DevOps Git Project

## Overview

This project demonstrates a basic version-controlled DevOps workflow using Git and GitHub.

## Objectives

- Use Git for version control
- Work with multiple branches
- Create and manage feature branches
- Use Pull Requests for merging changes
- Maintain project files using `.gitignore`
- Create and manage Git tags

## Branching Strategy

- `main` – Stable and release branch
- `dev` – Development branch
- `feature/add-project-page` – Feature development branch

## Technologies Used

- Git
- GitHub
- HTML
